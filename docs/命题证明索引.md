## 九项新增证明的方法

| 验证条件 | 推导方法 |
| --- | --- |
| `LOS_ListHeadInsert_return_wit_1` | 展开目标、引入参数，使用断言自反性 `reflexivity` |
| `LOS_ListHeadInsert_partial_solve_wit_1` | 展开目标后对原样保留的字段与列表资源使用 `reflexivity` |
| `LOS_ListTailInsert_partial_solve_wit_1` | 用 `entailer!` 调整分离合取中的资源顺序 |
| `LOS_ListTailInsert_partial_solve_wit_2` | 用 `entailer!` 匹配新节点、哨兵、尾部和链段资源 |
| `LOS_ListDelete_safety_wit_1` | `entailer!; lia` 证明第一次写零前的整型常量范围 |
| `LOS_ListDelete_safety_wit_2` | `entailer!; lia` 证明第二次写零前的同一范围 |
| `LOS_ListDelete_partial_solve_wit_1` | 计算展开具体单节点链段，提取见证、代入地址后匹配字段资源 |
| `LOS_ListDelete_partial_solve_wit_2` | 对另一字段排列展开链段并匹配更新后的邻接资源 |
| `LOS_ListDelete_partial_solve_wit_3` | 展开链段后，对指定的前驱后继字段使用 `store_ptr_undef_store_ptr`，保留字段权限 |

删除资源证明中的关键形式为：

```coq
cbn [dllseg_shift DLL.ptr DLL.data].
Intros x.
subst x.
sep_apply (store_ptr_undef_store_ptr
  (&(prev # "LOS_DL_LIST" ->ₛ "pstNext")) node_pre).
entailer!.
```

最后一步的弱化仅用于第三项资源证明；前两项保留具体字段值。`undef` 表示未指定该字段的值，仍保留写权限。
